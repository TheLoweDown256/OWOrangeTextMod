# Mod That Automatically Colours Jam Themes Orange
![Mod Thumbnail](https://github.com/user-attachments/assets/5cc4fc69-2ec7-4a54-8ee9-972157b557b9)

Adds the <color=orange><\/color> tag to all instances of the text "clockwork", "layers", "bigger on the inside", "hidden in plain sight", "community", "escape", "isolation", "miniature", "past", and "future". Also applies to different tenses like "escaping" and "layered".
